TOPIC
    about_ZxNextRemote

SHORT DESCRIPTION
    Drive the SD card of a ZX Spectrum Next from PowerShell, through
    ZX-Next-Unite's NextSync HTTP bridge.

LONG DESCRIPTION
    The module wraps the bridge's HTTP routes (HTTP_BRIDGE.md in the repo)
    in three layers of objects. The exported functions build them; with
    `using module` the classes can also be instantiated directly.

    ZxNextRemoteConnection            (New-ZxNextRemoteConnection)
        Where the bridge is: IpAddress, Port (80), optional bearer Token
        (sent as the ZXNEXTUNITE-BRIDGE-TOKEN header), and the two timeout
        tiers TimeoutSec (quick verbs, 60 s) / LongTimeoutSec (transfers,
        900 s). The token is BRIDGE-scoped: one bridge = one connection =
        one token, and everything sharing the connection (the ZxNextRemote
        root and every session it mints) sends it on every request -
        seats/sessions never carry tokens of their own.

    ZxNextRemote                      (New-ZxNextRemote)
        The client root. Constructors:
            [ZxNextRemote]::new($connection)
            [ZxNextRemote]::new($connection, $bearer)   # '' = no token
            [ZxNextRemote]::new($ip, $port, $bearer)
        A non-empty $bearer is set on the connection and rides every
        request (sessions from ManageSession inherit it). Methods:
          Test()               $true when the bridge answers /status.
          Status()             typed /status: Listening, Connected, Current,
                               Drives, Partitions, InFlight, and on the app
                               host Sessions/Active.
          Session()            typed /sessions: .Current = number of Nexts
                               connected, .List = ZxNextSessionInfo[] (each
                               Sid/Addr/Name/Label/Active), .Active, .Max.
          ManageSession($info) bind one seat (a ZxNextSessionInfo from
                               Session().List, or a bare sid [int]) - every
                               call on the returned session rides that seat
                               and never moves the app's active selection.
          ManageSession()      no argument: the ACTIVE seat.
          ForceExit()          /forceexit - every seated Next leaves -listen
                               and exits cleanly to BASIC (a broadcast).
          Help()               the bridge's own route reference (text).
          Close()              close THIS CLIENT only. Deliberately not a
                               /forceexit: nothing is sent, the Next stays
                               in -listen; further calls on this object
                               throw reason 'ConnectionClosed'.

    ZxNextRemoteSession               (from ManageSession)
        The per-seat proxy - the object you actually work with. Also
        constructible standalone, with the bearer token riding on every
        request it makes:
            [ZxNextRemoteSession]::new($connection)          # active seat
            [ZxNextRemoteSession]::new($connection, $sid)    # one seat
            [ZxNextRemoteSession]::new($ip, $port, $token)         # inline
            [ZxNextRemoteSession]::new($ip, $port, $token, $sid)   # inline
        Methods:
          Ls() / Ls($path)         ZxNextRemoteFileEntry[] (Dir, Size,
                                   Name, and Path pre-joined so an entry
                                   feeds straight back into Get/Rm/Crc/Sum).
          Exists($path)            $true when the file/folder exists
                                   (implemented as an Ls of the parent).
          Get($path)               the file as [byte[]].
          Get($path, $localPath)   save it locally; returns the FileInfo.
          Get($entry[, $local])    same, straight from an Ls() entry.
          Put($localPath, $remote) upload a file.
          Put([byte[]], $remote)   upload from memory.
          Crc($path)               the file's CRC-32 computed ON THE NEXT
                                   (/crc): .Crc32 = 8 upper-case hex digits
                                   (IEEE - zlib/7-Zip/PKZIP's), .Path. Only
                                   8 characters travel, not the file. Needs
                                   a listener with the crc op (.sync5 dot
                                   5.9.2+, ZX Next Remote 1.0.8+); an older
                                   one throws reason NextRefused.
          Crc($entry)              same, straight from an Ls() entry.
          LocalCrc32([byte[]])     the PC-side digest in Crc()'s shape, so a
          LocalCrc32($localPath)   script can compare the two itself (and
                                   print both on a mismatch).
          VerifyCrc($local, $remote)   strict CRC-32 proof a Put landed
          VerifyCrc([byte[]], $remote) intact: $true/$false from the two
                                   digests; THROWS (NextRefused) when the
                                   Next cannot be asked - an old listener, a
                                   file that did not open - so "unverified"
                                   is never mistaken for "verified".
          Sum($path)               size + 16-bit additive checksum, as the
                                   file reads back OFF THE NEXT (/sum pulls
                                   the whole file through the bridge - slow,
                                   but every listener supports it).
          Verify($local, $remote)  $true when the upload landed intact, by
          Verify([byte[]], $remote) the best proof the far side offers: the
                                   CRC-32 computed on the Next when its
                                   listener answers /crc, else the size +
                                   sum16 read-back (the pre-1.1.0 behaviour).
                                   A file the Next cannot read fails both
                                   ways and throws.
          MkDir/RmDir/RmTree/Rm($path)
          Ren($from, $to)          rename / move (same drive).
          Rcpy($src, $dst)         copy ON the Next, partitions included.
          RfSize($path)            files/folders/bytes of a tree.
          Free([$drive])           free space; Drives() the drive roster.
          ForceExit()              same broadcast as the root's.

    Remote paths accept an optional drive prefix (m:/backup), like every
    NextSync command. All calls are synchronous: the -listen session behind
    the bridge runs one command at a time.

ERROR HANDLING
    Every failure is thrown as a ZxNextRemoteError. Catch it and branch on
    .Reason (never on message text):

      TokenRequired       HTTP 401: the bridge requires the bearer token
                          (Settings -> "Require bearer token") or the one
                          supplied is wrong. Fix: set Token on the
                          connection.
      OsProtected         HTTP 401 with an 'os-protected' body: the remote
                          machine is ZX Next Remote with OS protection on,
                          and a WRITE verb (put/mkdir/rmdir/rm/ren/rcpy)
                          hit a guarded folder. The token is fine and
                          reads still work: fix it on that machine.
      SessionGone         HTTP 410: the seat left. Session() again, rebind.
      NoNextConnected     HTTP 503: bridge up, no Next in -listen.
      Timeout             HTTP 504, or the local timeout tripped.
      BadRequest          HTTP 400: bad arguments.
      NextRefused         HTTP 502: the Next reported a failure - also
                          what /crc (Crc/VerifyCrc) answers on a listener
                          that predates the crc op (.sync5 dot < 5.9.2,
                          ZX Next Remote < 1.0.8); Verify() falls back to
                          /sum on it, the strict methods let it through.
      Unsupported         HTTP 501: this bridge host lacks the verb
                          (nextsync5.py has no /rmtree).
      BridgeUnreachable   no HTTP answer at all (wrong address, bridge
                          off, firewall).
      ConnectionClosed    this client object was Close()d.

      try { $s.Put($file, '/home/incoming.nex') }
      catch [ZxNextRemoteError] {
          switch ($_.Exception.Reason) {
              'TokenRequired' { ... }
              'OsProtected'   { ... }
              default         { throw }
          }
      }

    Note: `catch [ZxNextRemoteError]` needs the type visible - use
    `using module ZxNextRemote` in scripts. With plain Import-Module,
    catch everything and read $_.Exception.Reason (present only on this
    module's errors; probe with $_.Exception.PSObject.Properties['Reason']).

EXAMPLES
    using module ZxNextRemote            # or Import-Module + the functions

    $bearer   = ''    # paste the bridge's token here when ZX-Next-Unite's
                      # Settings -> "Require bearer token" is enabled;
                      # '' = unprotected bridge. Passed on every request.
    $con      = [ZxNextRemoteConnection]::new('10.0.0.8', 80)
    $remote   = [ZxNextRemote]::new($con, $bearer)
    $sessions = $remote.Session()
    "{0} Next(s) connected" -f $sessions.Current
    $s        = $remote.ManageSession($sessions.List[0])

    $list = $s.Ls('/games')
    $s.Get($list[0], "$env:TEMP\first-file")
    $s.Put('build\game.nex', '/home/incoming.nex')
    if (-not $s.Verify('build\game.nex', '/home/incoming.nex')) { throw 'bad copy' }
    # ...or show your work: the two CRC-32s, the Next's and yours
    $s.Crc('/home/incoming.nex').Crc32          # e.g. 1A2B3C4D, computed on the Next
    $s.LocalCrc32('build\game.nex')             # the same 8 digits when it landed intact
    $remote.Close()
